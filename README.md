## 🛠️ Local Development & Quick Start

This portfolio is completely static with zero build dependencies:

```bash
# Clone the repository
git clone https://github.com/VedantKale244/portfolio.git
cd portfolio

# Run locally using the built-in multi-threaded SPA server
python server.py

# Open in your browser
http://127.0.0.1:8080/office
```

Or run with any standard static HTTP server:
```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .
```
